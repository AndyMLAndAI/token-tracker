Architecture & Privacy

Token Tracker operates with complete zero-cloud telemetry.

TOKEN TRACKER • LOCAL RUNTIME AGREEMENT ==================================================================== Token Tracker runs 100% locally on your computer. 1. LOCAL LOG INGESTION - Token Tracker parses local conversation logs from your home directory: ~/.claude/projects/ ~/.antigravity/ VS Code globalStorage (Cline & Roo Code) .aider.chat.history.md - No prompts, transcripts, code, or workspace paths are ever transmitted to any cloud server or third-party telemetry collector. 2. LOCAL SQLITE STORAGE - All token metrics and financial cost aggregations are stored in ~/.token_tracker/token_tracker.db using SQLite WAL mode. - You maintain complete ownership and direct SQL access to all data. 3. NETWORK ISOLATION - The application does not require internet access for core telemetry. - The optional loopback proxy operates exclusively on 127.0.0.1. ====================================================================
